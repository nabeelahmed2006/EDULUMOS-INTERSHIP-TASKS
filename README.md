# EDULUMOS-INTERSHIP-TASKS
TASK 1:
Face Detection System using OpenCV:


This project is a real-time Face Detection System built using Python and the OpenCV library. It utilizes the Haar Cascade algorithm to identify human faces through a live webcam feed or static images. This project serves as a foundational implementation of Computer Vision, with the potential to be extended into facial recognition, crowd counting, or automated attendance systems.

TASK 2:
Face Recognition Based Attendance System
📝 Project Overview
This project is an automated Attendance Management System that uses Computer Vision and Machine Learning to recognize faces and log attendance in real-time. It eliminates the need for manual registers by identifying users through a webcam and storing their attendance data (Name and Timestamp) in a CSV file.
